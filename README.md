# josueantuanB.github.io

Archivos que deben vivir en la raíz del dominio `josueantuanb.github.io`.

GitHub Pages publica cada proyecto en una subcarpeta (por ejemplo, [Tuins](https://josueantuanb.github.io/tuins/) en `/tuins/`), pero los buscadores y los asistentes de IA solo leen estos archivos en la raíz:

- `robots.txt`: permite el rastreo y declara el sitemap de Tuins.
- `llms.txt`: resumen del sitio de Tuins para asistentes de IA.

Si Tuins agrega o quita páginas, actualiza `llms.txt` aquí y `sitemap.xml` en [su repositorio](https://github.com/josueantuanB/tuins).
